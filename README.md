# Job search deadlines

Track job applications, deadlines, and submission history on iPhone and iPad.

## Installation

```sh
git clone https://github.com/P4suta/job-hunter-note.git
cd job-hunter-note
```

## Usage

```sh
open JobHunterNote.xcodeproj
```
