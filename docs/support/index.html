Job Hunter Note Support Privacy

App support

Use GitHub Issues to contact the developer about Job Hunter Note (未来探しくん).

Include your device model, operating system version, and the steps that led to the problem.

Issues are public, so use sample names in descriptions and screenshots.

Evening reminders

Enable the reminder when saving a deadline and allow notifications in Settings.

The app schedules one notification at 19:00 on the preceding local day for each date with unfinished tasks.

Submission history

After marking a task complete, open the 応募先 tab and select the employer to see the completed task.
